# Publish GitHub Profile README

GitHub profile README only works when the file is placed at:

```text
https://github.com/yaokai123/yaokai123
README.md
```

## Steps

1. Open GitHub and create a new repository named exactly:

```text
yaokai123
```

2. Keep it public.

3. Add a `README.md` file in the repository root.

4. Copy the content from:

```text
D:\mutilagent\docs\github-profile\README.md
```

5. Commit the file.

6. Refresh:

```text
https://github.com/yaokai123
```

The profile page will render the README automatically.

## Notes

- The current machine does not have GitHub CLI installed, so this workspace cannot push the profile directly through `gh`.
- If you already have the `yaokai123/yaokai123` repository, replace only its root `README.md`.
- Keep personal email or website links out until you want them public.
